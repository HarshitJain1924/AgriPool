# Frontend (React + Tailwind)

This is a lightweight React scaffold that expects a backend API at http://127.0.0.1:8000/api/

Steps:
1. Install node & npm.
2. cd frontend
3. npm install
4. npm start

Tailwind is configured via postcss; if `npm install` runs successfully it will install tailwind packages.

API calls are done via `src/api.js` which sets baseURL to the Django backend.
